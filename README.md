# 生成式渲染研究与实测

## 内容

- EdenLive 官方复现、外部诊断案例与补充实验
- H20 / LightX2V 耗时、显存和计时边界
- SolarRenderer 方法、数据、质量评测与因果推理流程

本地实测和论文报告结果分别标注，不构成统一性能排名。12 段视频以 MP4 形式直接托管，网页内可播放。当前为飞书 480p 预览版本，非模型原始分辨率。此页面没有重新执行实验。
